# alwinwedsthabithal

A wedding invitation for Alwin D Raja and T. Thabithal, on 10 December 2026 in Vellore.

Serve this directory with `python3 -m http.server 8000` and open `http://localhost:8000`. Deploy the directory as a static site. No build step or environment variables are required.

The countdown uses the ceremony start time in Indian Standard Time. Calendar downloads contain separate events for the ceremony and reception.
